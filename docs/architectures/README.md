# polygram — model architectures, in n-orca

The SAE variants below are the most common upstream sources — they describe the **input** topology polygram consumes, not models polygram trains itself.

Each entry has a verified [n-orca](https://github.com/jascal/n-orca) architecture document (`.n.orca.md`) and a Mermaid flowchart (`.mmd`). Regenerate with `python scripts/generate_sae_docs.py` from the n-orca repo, or call the `build_sae` / `build_world_model` tools on the registered `n-orca` MCP server.
